# scripts
Collection of scripts to automate tasks, consider this work in progress.

## Windows (PowerShell)

| Folder | What it does |
|---|---|
| [windows/dell-debloat](windows/dell-debloat) | Detect, remove and block Dell background software on Windows 11 (dry run, undo path, verify mode) |
| [windows/scoop-auto-update](windows/scoop-auto-update) | Update Scoop and its apps and clean up, twice a month, with logs |
| [windows/mutagen-sync](windows/mutagen-sync) | Install Mutagen, set up SSH and sync sessions from a settings file, and check them |
